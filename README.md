# Infinity Pixelmon | Android

Repositório oficial de distribuição e atualização do **Launcher Infinity Pixelmon para Android**, desenvolvido para oferecer uma experiência prática, segura e otimizada aos jogadores do servidor Infinity Pixelmon.

## Download e atualizações

Baixe sempre a versão mais recente do launcher pela seção **Releases** deste repositório.

O launcher conta com um sistema de **atualização automática**, responsável por verificar a disponibilidade de novas versões e solicitar sua instalação por meio do procedimento oficial do Android.

As atualizações preservam os dados do aplicativo, incluindo contas, configurações personalizadas e arquivos do jogo, desde que sejam instaladas sobre o mesmo pacote, com assinatura compatível e sem desinstalação prévia.

## Segurança e transparência

- Os APKs oficiais são distribuídos com assinatura digital.
- As atualizações utilizam o mecanismo nativo de instalação do Android.

**Importante:** Para garantir a segurança e a integridade do launcher, utilize exclusivamente os APKs disponibilizados nas Releases oficiais deste repositório.
